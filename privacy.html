Privacy policy: signalbot-rclone and chimera-rclone

This policy covers both apps; "it" below means either of them.

Effective 21 October 2026.

Who uses it

Each is used only by its owner, to back up his own files to his own Google Drive. It is not offered to the public.

What it accesses

With the drive.file permission, it can see and change only the files and folders it created itself in the signed-in Google Drive. It cannot see any other file in that Drive.

What it collects and shares

Nothing. It sends no data to anyone other than Google Drive, and it keeps no analytics, logs or copies on any server. The access token Google issues is stored only in rclone's configuration file on the owner's own computers.

Google user data

Its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data is never sold, never transferred to third parties, and never used for advertising.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. The backed-up files stay in the owner's Drive until he deletes them.

Contact

Open an issue on this site's repository.
